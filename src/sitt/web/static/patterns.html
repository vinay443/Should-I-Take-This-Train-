      How these numbers are worked out

      NTES's live board is read only when someone presses Check live first or runs sitt-collect, so a train is usually seen a few times as it approaches, not at the moment it leaves.

      Each train at a station on a day counts once, with the delay of its last reading, and only if that reading was taken within 15 minutes of the train's time. Earlier readings often say "on time" for trains that end up late (see docs/live-drift.md), so using them would make things look better than they were.

      Only real readings of suburban trains are used, never the synthetic test data.
